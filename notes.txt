Заметки о Git:
Git — система контроля версий.
Команда git clone создает локальную копию репозитория.
Команда git status показывает состояние файлов.
Команда git push отправляет коммиты на GitHub.
Команда git pull получает изменения из удаленного репозитория.

Второй разработчик работает в ветке dev2.
Изменения в этом файле не затрагивают работу других разработчиков.
